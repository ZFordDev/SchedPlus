# Security Policy

SchedPlus is built to keep your tasks local and your data yours.

Security matters, even for a little task planner!

## Found a security issue?

Please don't open a public issue.

Instead, report it privately through [GitHub Security Advisories](https://github.com/ZFordDev/SchedPlus/security/advisories/new).

If possible, include:

- What went wrong.
- How to reproduce it.
- Which version is affected.
- Any potential impact.

Don't worry if you don't have all the details. Just share what you know!

## Supported versions

Security fixes generally target the latest release. Older versions may not receive updates.

## A few things to know

- Tasks and preferences are stored locally.
- No accounts or cloud services are required.
- Application updates use verified release information where supported.
- SchedPlus doesn't collect analytics or telemetry.

For more about how your data is handled, see [PRIVACY.md](PRIVACY.md).
